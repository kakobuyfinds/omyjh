How to use a SuperBuy spreadsheet

  1. Find the original seller listing. Open HipobuyFind and match the item ID and title. If the product page supplies a seller link, open it and confirm the color and size before using it with your shopping agent.
  2. Compare measurements in centimeters. For a top, record the laid-flat chest width and body length. For shoes, look for insole length. Keep the seller’s size chart and variant name with the link.
  3. Review warehouse QC photos. If your agent supplies quality-control photos, compare the photographed item with your chosen variant. Ask for a measurement photo if fit depends on one dimension, and check return deadlines before approving shipment.
  4. Estimate landed cost. Add the item price, domestic delivery, agent fees, international shipping, and any applicable taxes or duties. Check whether the shipping line charges by actual or volumetric weight.

Frequently asked questions

Where do the two main buttons go?

Both open the HipobuyFind homepage. This independent guide uses HipobuyFind as its catalog source.

Can I order every listed item using SuperBuy?

Open the original seller link and check whether your agent accepts it and whether the item can ship to your destination. Availability can change between browsing and ordering.

What should I record in my own spreadsheet?

Save the seller URL, item ID, color, size, measurement, CNY price, date checked, estimated shipping, and any QC notes. Keep the exact variant name so you can match it to later photos.
